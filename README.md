# The Celia Project

A static public site for The Celia Project, including the landing page, mission
page, judge overview, news archive, contact page, and preview page. The current
visual direction is a clean white-and-gold public presentation.

## Open

Open `index.html` directly in a browser, or serve this folder locally:

```bash
python3 serve.py
```

Then visit `http://127.0.0.1:8788`.

## Pages

- `index.html`: landing page
- `mission.html`: mission and project framing
- `judges.html`: judge models and evaluation overview
- `roadmap.html`: news archive
- `news/`: individual research updates
- `contact.html`: contact page
- `preview-celia.html`: preview page

## Assets

- `assets/css/styles.css`: the full design system (one shared stylesheet)
- `assets/js/site.js`: nav active-state, scroll reveals, and page interactions
- `assets/images/celia-project-mark.svg`: editable SVG mark used in the nav and favicon
- `assets/images/celia-logo-transparent-v2.png`: primary Celia logo
- `assets/images/celia-hero-observatory.png`: landing hero visual
- `assets/images/celia-judge-prism.png`: judge-page visual
